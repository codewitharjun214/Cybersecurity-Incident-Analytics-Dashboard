# 🛡️ Cybersecurity Threat Intelligence & Incident Analytics Dashboard

An end-to-end **Data Analytics Project** that analyzes global cybersecurity threats from **2015–2024** using **Python, SQL, and Power BI**. This project demonstrates the complete analytics workflow including **data cleaning, exploratory data analysis (EDA), SQL analysis, DAX calculations, and interactive dashboard creation**.

---

## 📌 Project Overview

Cybersecurity incidents continue to increase across industries worldwide. This project analyzes thousands of cybersecurity incidents to identify:

- 📈 Incident trends over time
- 💰 Financial impact across industries
- 🌍 Countries most affected
- 🛡️ Common defense mechanisms
- 🎯 Attack type distribution
- ⏱️ Relationship between resolution time and financial loss

The goal is to transform raw cybersecurity data into actionable business insights through an interactive Power BI dashboard.

## 📈 Key Business Insights

- Financial losses exceeded **151K Million**
- More than **2 Billion users** were affected
- **3000 cybersecurity incidents** were analyzed
- Incidents impacted **10 countries**
- **7 industries** were targeted
- Higher resolution time generally led to greater financial loss
- Banking and IT sectors experienced the highest financial impact
